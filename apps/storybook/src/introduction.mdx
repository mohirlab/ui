# Mohirlab

_Mohir_ (Uzbek) means a master craftsman. The design system follows from that: warm
paper and ink neutrals, a deep lapis accent, calm modern surfaces, a square seal that marks
state, and imagery generated from tilework geometry.

## How this showcase is organised

| Section         | What is there                                                                                     |
| --------------- | ------------------------------------------------------------------------------------------------- |
| **Foundations** | Color ramps and roles, typography, spacing and radius, elevation, the icon set, generated imagery |
| **Components**  | Every component with live controls and its full variant grid                                      |
| **Patterns**    | Real compositions (posts, events, products, courses, invites), mobile-first                       |

**Example websites:** see the system in real products: a community app, a marketing site and a SaaS dashboard at [mohirlab.github.io/ui/examples](https://mohirlab.github.io/ui/examples/).

Use the toolbar to switch **light / dark** and to preview on **phone** and **tablet** sizes.
The **Accessibility** panel runs axe on every story.

## Packages

| Package               | Role                                                  |
| --------------------- | ----------------------------------------------------- |
| `@mohirlab/tokens`    | DTCG design tokens → JS, types, CSS variables, JSON   |
| `@mohirlab/themes`    | Theme contract, light and dark themes, cascade layers |
| `@mohirlab/sprinkles` | Token-bound responsive utilities                      |
| `@mohirlab/recipes`   | Variant recipes and shared conventions                |
| `@mohirlab/motion`    | Enter/exit motion with reduced-motion fallbacks       |
| `@mohirlab/icons`     | Square-capped line icons as framework-free data       |
| `@mohirlab/assets`    | Seeded generative artwork and avatars                 |
| `@mohirlab/react`     | React components                                      |

Everything here imports the **built** packages, exactly as an app installed from npm would.
