# @mohirlab/tokens

Canonical design tokens for the Mohirlab design system, in DTCG format.

Part of [Mohirlab](https://github.com/mohirlab/ui), an open-source design system built on Vanilla Extract.

```sh
pnpm add @mohirlab/tokens
```

```ts
import { color, space, modes } from '@mohirlab/tokens';
// or plain CSS variables: import '@mohirlab/tokens/tokens.css';
```

See the [documentation and Storybook](https://github.com/mohirlab/ui#readme). MIT licensed.
