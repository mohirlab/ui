# @mohirlab/recipes

Variant recipes and shared style conventions for building Mohirlab components.

Part of [Mohirlab](https://github.com/mohirlab/ui), an open-source design system built on Vanilla Extract.

```sh
pnpm add @mohirlab/recipes
```

```ts
// button.css.ts
import { componentRecipe, compose, focusRing, keycap } from '@mohirlab/recipes';
```

See the [documentation and Storybook](https://github.com/mohirlab/ui#readme). MIT licensed.
