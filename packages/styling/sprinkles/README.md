# @mohirlab/sprinkles

Type-safe, token-bound responsive utility classes for Mohirlab.

Part of [Mohirlab](https://github.com/mohirlab/ui), an open-source design system built on Vanilla Extract.

```sh
pnpm add @mohirlab/sprinkles
```

```ts
import '@mohirlab/sprinkles/styles.css';
import { sprinkles } from '@mohirlab/sprinkles';
const cls = sprinkles({ padding: { mobile: '3', desktop: '6' }, background: 'surface' });
```

See the [documentation and Storybook](https://github.com/mohirlab/ui#readme). MIT licensed.
